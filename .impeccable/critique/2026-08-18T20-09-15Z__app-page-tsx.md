## Priority Issues

[P0] Failed or refused generation destroys the result being read. app/page.tsx setResult(null) + sessionStorage clear before fetch. Any 402/403/429/500/timeout empties the screen; no history means permanent loss. Two clicks to reproduce. Fix: keep old result until response.ok; restore on failure; confirm "Generate again" when remaining <= 1.

[P0] The unit being spent is invisible when spending. usage.remaining returned by both /api/generate and /api/account; generate page discards it. Users learn the limit by refusal. Fix: "2 packs left" beside the CTA from data already on the wire.

[P1] Half the document you are told to check is unreachable. "Read it before you send it" is 12px footer text; the reading surface hides 47%/53% at tabIndex -1, so keyboard users cannot scroll it. Mobile forces holding 3 gaps across 901px. Fix: tabIndex 0 + role=region + label; raise the instruction; full-height on mobile.

[P1] The 60s wait is unseen, uncancellable, unannounced. Progress card top at y=802 on a 900px viewport with no scroll-to. No AbortController in the repo. GenerationProgress holds the only role=status and unmounts when results appear. Fix: scroll on submit; Cancel that aborts and releases the slot; persistent live region; document.title.

[P2] Destructive profile editing with no guard. No beforeunload, no AbortController, no confirm() anywhere in the codebase. X deletes a typed role instantly; failed save renders thousands of px from the fixed Save bar. Fix: undo-toast, dirty guard, errors inside the save bar.
